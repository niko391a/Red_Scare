Group A - Algorithm Design, MSc CS (Autumn 2026)

## Setup Venv
1) Create: `python -m venv .venv`
2) Activate: `source .venv/bin/activate`
3) Install libraries: `pip install -r requirements.txt`
4) Deactivate when done: `deactivate`

## To Install without venv
```
pip install matplotlib networkx scipy PyQt6
```

# Generate results.txt
The command below will generate a text file in the root folder called `results.txt`:

`python .\runAll.py`
